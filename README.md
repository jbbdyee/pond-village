# 🎣 연못마을 (Pond Village)

> **AI 주민들은 공동 연못을 지킬 수 있을까?**
> 공유지의 비극과 거짓 소문을 실험하는 멀티 에이전트 시뮬레이션

LLM으로 움직이는 AI 어부 5명이 연못 하나를 나눠 쓰는 작은 어촌 마을입니다.
어부들은 매일 광장에서 이야기하고, 각자 몰래 물고기를 잡고, 저녁에 일기를 씁니다.
많이 잡으면 당장 돈을 벌지만, 모두가 욕심을 내면 연못은 바닥나고 마을은 무너집니다.

> 🚧 **진행 중인 프로젝트입니다.** 아직 실험 결과는 없습니다.

## 왜 이 실험인가

실제 멀티 에이전트 시스템도 같은 문제를 겪습니다.

- **공유 자원** — 여러 에이전트가 API 예산·서버 자원을 함께 씁니다.
- **오류 전파** — 한 에이전트의 환각이 다른 에이전트에게 사실처럼 전달됩니다.

이 두 문제를 눈에 보이고 측정 가능한 작은 마을로 옮겨 실험합니다.

## 실험 질문

### 1단계 · 공유지의 비극
1. LLM 에이전트는 공동 연못을 지속 가능하게 쓰는가?
2. 대화와 규칙 투표가 가능하면 결과가 달라지는가?

| 조건 | 광장 대화 | 규칙 투표 | 위반 처벌 |
|---|---|---|---|
| A. 고립 | ✗ | ✗ | ✗ |
| B. 대화 | ✓ | ✗ | ✗ |
| C. 자치 | ✓ | ✓ (3일마다) | 벌금 |

### 2단계 · 거짓 소문
1. "연못이 곧 바닥난다"는 거짓 소문이 마을에 퍼지는가?
2. 소문을 들은 어부는 사재기를 하는가, 직접 확인(`inspect_pond`)하는가?
3. 대화·자치가 있는 마을은 소문에 더 강한가, 약한가?

## 마을의 규칙

- 연못에는 최대 100마리. 하루가 끝나면 남은 물고기가 2배로 늘어납니다 (상한 100).
- 5마리 미만으로 줄면 연못은 붕괴합니다.
- 어부는 정확한 재고를 모르고, 매일 아침 **오차가 있는 추정치**만 듣습니다.
- 물고기 1마리 = 1원, 하루 생활비 5원. 3일 연속 빚이면 마을을 떠납니다.

**판정은 코드가 합니다.** 어획 배분·재생·돈·파산은 모두 규칙 엔진이 결정하고,
LLM은 "무엇을 하고 싶은지"만 말합니다.

## 하루 흐름

| 순서 | 페이즈 | 내용 |
|---|---|---|
| 1 | 아침 공지 | 날짜, 연못 추정치, 전날 총 어획량 |
| 2 | 광장 | 전체에게 말하거나 한 명에게 귓속말 |
| 3 | 어획 | 몰래 `fish(amount)` 또는 `inspect_pond` |
| 4 | 정산 | 규칙 엔진이 배분·판매·생활비·재생 처리 |
| 5 | 회의 | (조건 C) 3일마다 쿼터 제안·투표 |
| 6 | 일기 | 오늘 요약, 연못에 대한 믿음, 이웃 신뢰도 기록 |

## 진행 상황

- [ ] P0 프로젝트 셋업
- [ ] P1 월드 + 규칙 엔진
- [ ] P2 스크립트 봇 + 기준선 (탐욕 → 붕괴, 협력 → 유지)
- [ ] P3 SQLite 로그
- [ ] P4~P6 LLM 에이전트 (어획 → 기억·일기 → 광장 대화)
- [ ] P7 Streamlit 대시보드
- [ ] P8 규칙 투표
- [ ] P9~P10 1단계 실험
- [ ] P11~P12 2단계 소문 실험

## 기술 스택

- Python 3.11+, `uv`
- LLM: OpenAI 호환 API (개발: Ollama 로컬 / 본 실험: 저가 유료 모델)
- SQLite · Streamlit · pytest
