# IMP-PLAN — 연못마을

각 단계는 **완료 기준**을 만족해야 다음으로 넘어간다.
**설명 체크**는 내가(사용자) 직접 답할 수 있어야 하는 질문이다. 답 못 하면 다음 단계로 가지 않는다.

---

## P0. 프로젝트 셋업
- `uv init`, 폴더 구조 생성, pytest 동작, `.gitignore`에 `runs/`
- Ollama 설치 + 모델 하나 받아서 OpenAI 호환 엔드포인트로 "hello" 호출

**완료 기준**: `uv run pytest` 통과, `uv run python -m pondvillage.llm --ping`이 로컬 모델 응답 출력
**설명 체크**: 왜 Ollama와 유료 API를 같은 클라이언트로 부를 수 있는가?

## P1. 월드 + 규칙 엔진 (LLM 없음)
- `world.py`, `rules.py`: 연못 재생, 어획 배분, 판매, 생활비, 파산, 붕괴
- `tests/test_rules.py`: 배분 비율, 재생 상한, 파산 3일, 붕괴 경계값

**완료 기준**: 규칙 테스트 전부 통과
**설명 체크**: 요청 합계가 재고보다 많을 때 어떻게 나누는가? 지속 가능한 총 어획량이 왜 50인가?

## P2. 스크립트 봇 + 러너 + 기준선
- `agents/scripted.py`: 탐욕 / 협력 / 랜덤 봇
- `runner.py`: 하루 페이즈 진행 (LLM 페이즈는 봇이 대신)
- 결과를 콘솔 표로 출력

**완료 기준**: 탐욕 봇 마을은 붕괴하고, 협력 봇 마을은 30일 유지된다
**설명 체크**: 왜 LLM보다 봇을 먼저 만들었는가? (규칙 검증 + 비교 기준선)

## P3. 로그 (SQLite)
- `logger.py`: SPEC 7장의 테이블 생성과 기록
- 봇 실행 결과가 DB에 남는지 확인

**완료 기준**: 실행 후 `runs/<run_id>.db`에서 days, agent_days 조회 가능

## P3.5 마을 미리보기 화면 (대시보드 v0)
- Streamlit: run 선택 → 날짜별 연못 재고, 어부별 돈만 보여주는 작은 화면
- 봇 실행 결과만 쓰므로 LLM 비용 0원. 같은 와이파이의 휴대폰에서도 열 수 있다
- P7(대시보드 v1)은 이 화면을 넓혀서 만든다

**완료 기준**: 탐욕 봇 마을과 협력 봇 마을의 재고·돈 변화를 화면에서 비교할 수 있다

## P4. LLM 에이전트 — 어획만
- `llm.py`: 호출, JSON 파싱, 재시도, `llm_calls` 기록, 비용 계산, 비용 상한
- `agents/llm_agent.py`: 아침 공지 + 상태 → `fish` / `inspect_pond`
- 프롬프트는 `src/pondvillage/prompts/`에 파일로 분리

**완료 기준**: LLM 에이전트 5명이 로컬 모델로 5일 진행, 파싱 실패해도 크래시 없음
**설명 체크**: 파싱 실패 시 어떻게 처리하는가? 프롬프트에 무엇을 넣고 무엇을 뺐는가?

## P5. 기억 + 일기
- `memory.py`: 최근 2일 원본 + 이전 요약
- 일기 페이즈: summary, beliefs, trust JSON

**완료 기준**: 10일 실행 시 프롬프트 토큰이 날짜에 비례해 계속 늘지 않는다 (로그로 확인)
**설명 체크**: 왜 전체 기억을 다 넣지 않는가?

## P6. 광장 대화
- `say` (전체 / 귓속말), 발언 순서 시드 섞기
- 귓속말은 받는 사람 기억에만 들어감

**완료 기준**: 조건 A(대화 없음)와 B(대화 있음)를 설정으로 전환 가능

## P7. 대시보드 v1
- Streamlit: run 선택 → 날짜별 재고 그래프, 에이전트별 돈·어획량, 대화 타임라인, 일기 보기

**완료 기준**: 실행 하나를 대시보드에서 처음부터 끝까지 따라가며 읽을 수 있다

## P8. 규칙 투표 (조건 C)
- 3일마다 회의: 제안 → 투표 → 과반이면 쿼터 시행
- 위반 기록 + 벌금

**완료 기준**: 조건 C에서 규칙이 통과되고, 위반 시 벌금이 정산에 반영된다

## P9. 실험 러너 + 분석
- `configs/exp1_*.yaml`, 조건 × 시드 일괄 실행 (`--paid` 없으면 로컬)
- 분석 스크립트: EXPERIMENT 1단계 지표 계산 → 비교 표 + 그래프

**완료 기준**: 로컬 모델로 1단계 전체(9회)를 짧게(10일) 돌려 지표 표가 나온다

## P10. 1단계 본 실험 (유료)
- 저가 API 모델로 30일 × 9회 실행
- 결과 정리 → `docs/RESULTS-1.md`

**완료 기준**: 비용 상한 내에서 완료, 지표 표 + 그래프 + 인상적인 로그 3개

## P11. 소문 기능 (2단계)
- `rumor.py`: 주입, 키워드 + LLM 판정, `is_rumor` 기록
- 대시보드: 확산 네트워크 그래프, 믿음 변화 그래프

**완료 기준**: 로컬 모델로 R1 실행 시 소문 확산 경로가 그래프로 보인다
